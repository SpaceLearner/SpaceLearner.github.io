Jiayan Guo

I study general-purpose agents at Tencent.

How can the same agent handle unfamiliar tasks that take many steps? I’m interested in how it revises a plan when new evidence comes in, and what it learns from one attempt that helps with the next. My current work spans recursive self-improvement, multi-agent systems, and agent harness design.

Before joining Tencent, I studied search and embodied agents at Alibaba DAMO Academy. I was the corresponding author on ZeroSearch and co-led RynnBrain. I received my Ph.D. from Peking University in 2024.

Selected work

Search

ZeroSearch

Corresponding author · 2025

In ZeroSearch, a second language model generates the documents a search agent receives for each query. During reinforcement learning, we gradually reduce the quality of those documents so the agent learns to search even when the first results are poor.

Paper Code

InterLV-Search

Co-author · NeurIPS 2026, Evaluations and Datasets Track

We built this benchmark to test whether an image changes what a search agent looks for next. Tasks range from finding a piece of visual evidence to following leads across images and text on the open web. An offline setting lets researchers compare agents on the same material.

Paper Code

Embodied agents

RynnBrain

Project co-lead · 2026

RynnBrain uses a robot’s camera view to locate objects, follow how a scene changes, and plan what to do next. My work on the project covered pretraining, Chain-of-Point reasoning, vision-language-action modeling, and the infrastructure we used to train the model.

Paper Code Author contributions RynnBrain 1.1

WorldVLA

Co-author · 2025

We trained one autoregressive model to predict both a robot’s next action and the video frames that follow it. We later extended this work in RynnVLA-002, which now hosts the code.

Paper Code Model

RynnVLA series

Co-author · ICRA 2026 (001) · NeurIPS 2026 (002)

RynnVLA-001 learns from first-person videos of people handling objects, then uses trajectory modeling and ActionVAE to transfer what it learns to robot manipulation.

Paper Code Project overview

RynnVLA-002 extends WorldVLA with a continuous Action Transformer. It uses a wrist camera and the robot’s own state to predict actions and future observations together.

Paper Code Model

Earlier work

AIGB / DiffBid

First author · KDD 2024

DiffBid uses a conditional diffusion model to generate bids for an entire advertising campaign. In an online A/B test on Alibaba’s advertising platform, gross merchandise value rose 2.81% and return on investment rose 3.36%.

Paper

JGCF

First author · KDD 2023

JGCF uses Jacobi polynomials to filter signals on a graph of users and items. The filters let us study which parts of the graph signal help predict a user’s preferences.
